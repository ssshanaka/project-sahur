## My teaching style for this project

I don't want this to be "copy this notebook and press Run."

For every important piece of code, we'll answer four questions:

1. **What problem does this solve?**
2. **How does it work internally?**
3. **Why are we doing it this way instead of another?**
4. **What happens if we change these parameters?**

You'll also see diagrams of the data flow, inspect configuration files, and run small experiments to build intuition before moving on.

By the end, you shouldn't just know how to fine-tune **Qwen3-0.6B**—you should understand enough to pick up almost any modern open-weight transformer model and know how to adapt, evaluate, and ship it. That's the level we'll aim for.
