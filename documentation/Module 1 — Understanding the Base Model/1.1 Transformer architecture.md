# Before Transformers

Imagine reading this sentence:

> **"The cat that chased the mouse was hungry."**

Humans instantly know:

- "was hungry" refers to **the cat**
- not **the mouse**

Early neural networks (RNNs/LSTMs) struggled with this because they processed text **one word at a time**.

```
The → cat → that → chased → the → mouse → was → hungry
```

Each word had to wait for the previous one.

Problems:

❌ Slow

❌ Hard to parallelize

❌ Forgot long context

---

# The Big Idea (2017)

Google researchers published a paper called **"Attention Is All You Need."**

Instead of reading one word after another...

they asked:

> **"What if every word could look at every other word immediately?"**

That idea became the **Transformer**.

---

# What does a Transformer do?

Imagine every word in a sentence is sitting in a meeting room.

Sentence:

```
The cat chased the mouse.
```

Instead of reading left-to-right...

Every word looks around the room.

```
          cat
         ↗ ↑ ↖

The ←→ chased ←→ mouse
         ↘ ↓ ↙
```

Each word asks:

> "Who here matters to me?"

This is called **Attention**.

---

# The Entire Transformer Pipeline

Here's the high-level view:

```text
Input Text
      │
      ▼
Tokenizer
      │
      ▼
Token IDs
      │
      ▼
Embeddings
      │
      ▼
Transformer Block 1
      │
      ▼
Transformer Block 2
      │
      ▼
Transformer Block 3
      │
     ...
      │
Transformer Block N
      │
      ▼
Output Head
      │
      ▼
Next Token Prediction
```

Every LLM—Qwen, Llama, Gemma, Mistral—follows almost exactly this flow.

# What is inside ONE Transformer Block?

This is where the magic happens.

```
Input

↓

Attention

↓

Normalization

↓

Feed Forward Network

↓

Normalization

↓

Output
```

One block doesn't make the model intelligent.

The intelligence comes from stacking **many** of them.

Qwen3-0.6B has multiple Transformer blocks (the exact count is defined in its configuration, which we'll inspect later).

# What actually changes during training?

This is one of the biggest misconceptions.

The model **doesn't store words**.

It stores **numbers**.

Millions (or billions) of them.

Example:

```
Layer 5

Weight

0.827364
```

After training

```
0.831982
```

Tiny change.

Repeat billions of times.

Eventually...

The model learns language.

---

# What is a "weight"?

Think of a weight as a tiny dial.

```
Should I pay attention to cats?

0.15
```

Training changes it.

```
0.92
```

Now the model thinks:

> "Cats are really important in this context."

A model like Qwen3-0.6B contains roughly **600 million trainable parameters (weights)**.

---

# Fine-tuning doesn't rewrite the whole brain

Imagine your brain.

You already know English.

You decide to learn medicine.

You don't erase English.

You add new knowledge.

Fine-tuning is similar.

Instead of rebuilding all 600 million parameters from scratch, we'll use **LoRA** to train a much smaller set of additional parameters while leaving the original model weights frozen. We'll cover LoRA in depth in Module 7.

# Why are Transformers so powerful?

Because they can:

✅ Learn grammar

✅ Learn facts

✅ Learn reasoning patterns

✅ Learn programming syntax

✅ Learn personalities

✅ Learn writing styles

All using exactly the same architecture.

The architecture stays the same.

The data changes.

---

# One misconception

People often say:

> "The model thinks."

Technically...

It predicts.

Every step is:

```
Current Tokens

↓

Transformer

↓

Probability Distribution

↓

Pick Next Token

↓

Repeat
```

That's it.

But because it has been trained on vast amounts of text, those next-token predictions can exhibit sophisticated reasoning and planning behaviors.

---

# How this connects to Project Sahur

When we start training later, **we are not creating a new Transformer architecture**.

We're taking an existing Transformer (Qwen3-0.6B) and changing **how it behaves** by adapting its learned parameters.

Think of it like this:

```
Qwen3 Architecture
        │
        ├── Transformer blocks
        ├── Attention
        ├── Feed Forward Networks
        ├── Embeddings
        └── Output Head
                 │
                 ▼
         Project Sahur
      (new behavior, same architecture)
```

That's why a fine-tuned model can feel like a different assistant even though it's built on the same underlying architecture.
