```

)
```

## Step 1

```

```

## Step 2

Because otherwise numbers become enormous.

This keeps everything nicely scaled.

# Why is Flash Attention Amazing?

Normal Attention computes relationships between every pair of tokens, which becomes expensive as sequences grow longer.

Flash Attention reorganizes those computations to make far better use of GPU memory. Instead of repeatedly reading and writing huge intermediate matrices, it processes them in optimized chunks while producing the same mathematical result.

So you get:

- Same output
- Less memory traffic
- Faster execution
- Longer context windows

This is why modern inference engines love Flash Attention.

---

# How does this affect Project Sahur?

When we fine-tune Qwen later...

We're **not replacing the Attention algorithm**.

We're adjusting the learned weights inside layers that produce the Queries, Keys, Values, and other transformations.

Over time, those updated weights make the model learn new patterns—like a more natural conversational style or stronger instruction following—while the underlying Attention mechanism stays the same.
