# CUDA Driver

Lives on your computer.

Installed with NVIDIA drivers.

Responsible for talking to the GPU.

---

# CUDA Runtime

Lives inside PyTorch.

Handles

- launching kernels
- memory allocation
- tensor movement

You usually don't interact with it directly.

---

# CUDA Toolkit

This confuses everyone.

Toolkit

≠

Runtime

The **CUDA Toolkit** is for developers writing CUDA programs.

It includes things like:

- `nvcc` (CUDA compiler)
- debugging tools
- profilers
- CUDA libraries

PyTorch users usually **don't need the full toolkit** just to run models.

---

# What Happens When You Install PyTorch?

Suppose you install

```bash
pip install torch
```

Depending on the package you choose,

PyTorch may already include the CUDA runtime libraries it needs.

This is why many people can use GPU acceleration **without installing the full CUDA Toolkit**.

This also explains something you asked earlier in our conversations:

> "Why does Docker download CUDA again?"

Because many containers bundle their own compatible CUDA runtime instead of relying on your system-wide installation.

32 bits.

```text

```

# One Common Misconception

People often think

> "CUDA makes my code faster."

Not automatically.

CUDA **enables** GPU execution.

Whether your code becomes faster depends on:

- How much parallel work exists
- Data transfer overhead
- GPU utilization
- Model size
- Batch size

For tiny tasks, the CPU can actually be faster because moving data to the GPU introduces overhead.
