# What is a Tensor?

The word **tensor** scares people.

It shouldn't.

A tensor is simply:

> **A multi-dimensional array of numbers.**

That's it.

---

# Level 0 Tensor

```python

```

One number.

Shape

```text
()
```

This is called a **Scalar**.

---

# Level 1 Tensor

```python
[2,4,6]
```

Shape

```text
(3,)
```

One dimension.

Also called a **Vector**.

---

# Level 2 Tensor

```python
[
 [1,2],
 [3,4]
]
```

Shape

```text
(2,2)
```

This is a **Matrix**.

# Level 3 Tensor


Now we have a 3D tensor.

# Autograd

This is PyTorch's superpower.

Example

```python
x = torch.tensor(2.0, requires_grad=True)

y = x**2
```

PyTorch already knows

```text
y = x²
```

When you call

```python
y.backward()
```

It computes

```text
dy/dx = 2x
```

Automatically.

Since

```text
x = 2
```

Gradient

```text
4
```

No manual calculus.

---

# Optimizer

Think of the optimizer as the coach.

The gradient says

> Move this way.

Example

---

# Zero Grad

One strange line you'll see everywhere.

```python
optimizer.zero_grad()
```

Why?

PyTorch accumulates gradients.

Without clearing them,

every training step would keep adding new gradients to the old ones.

# One Common Misconception

People often think:

> "PyTorch is an AI framework."

More accurately, PyTorch is a **deep learning framework**.

It doesn't know anything about language, images, or Transformers.

It simply provides efficient tools for tensor computation, automatic differentiation, and neural network building.

Transformers, CNNs, diffusion models, and reinforcement learning systems can all be built with the same framework.
