# Why Attention Mask?

Imagine

```text
Hello bro
```

Length

2

Another sentence

```text
Hello

How are you today?
```

Length

5

Neural networks need equal-length inputs within a batch.

So we pad shorter sequences.

```text
Hello bro PAD PAD PAD
```

The attention mask tells the model

Ignore these PAD tokens.

# Why "Causal"?

Suppose

```text
I love pizza because
```

The model predicts

```text

```

Then

```text

```

Then

```text

```

One token at a time.

It only looks backward.

Never into future tokens.

Hence

"Causal"

# What are Logits?

Imagine

The model predicts

Next word.

Instead of directly saying

```text

```

It produces scores.

Example

```text

8.7
```

```text

5.3
```

```text

-2.1
```

These are

Logits.

Later

Softmax converts them into probabilities.

Highest probability wins (or is sampled).

# Device Mapping

Large models don't always fit on one GPU.

Transformers can automatically place different parts of a model on available devices.

```python
model = AutoModelForCausalLM.from_pretrained(
    MODEL_NAME,
    device_map="auto"
)
```

For Qwen3-0.6B, this usually isn't necessary, but it's invaluable for larger models.

# One Common Misconception

People often think:

> "Transformers is the AI."

Not exactly.

The **Transformers library** is a software framework.

The actual intelligence lives in the **trained weights** (`model.safetensors`).

Without those weights, the library is just code.

Without the library, the weights are just numbers on disk.

You need both.
