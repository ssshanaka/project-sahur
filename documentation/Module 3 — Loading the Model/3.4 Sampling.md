# Lesson 3.4 — Sampling Strategies (Greedy vs. Stochastic)

In **Lesson 3.3**, we built our first autoregressive generation loop using `model.generate()`. To keep things simple, we set `do_sample=False`, which defaulted to **Greedy Decoding**.

While greedy decoding works fine for rigid factual extraction, it has a major flaw: it makes language models sound static, robotic, and prone to repetitive loops.

In this lesson, we are going to learn the fundamental difference between **Deterministic Decoding** (Greedy) and **Stochastic Sampling** (Random Sampling). We will inspect how raw numerical scores (**Logits**) are converted into normalized probabilities (**Softmax**), and how toggling `do_sample=True` changes how our Transformer selects its next token.

_(Note: We will cover **Temperature** in Lesson 3.5, **Top-k** in Lesson 3.6, and **Top-p** in Lesson 3.7!)_

# Step 1 — Why does this even exist?

When Qwen3 runs a forward pass for a single token, the Language Model Head (`lm_head`) outputs a 1D tensor containing **151,646 raw floating-point numbers** called **Logits**.

If we always choose the token with the absolute highest logit score (called the **Argmax** operation), two things happen:

1. **Zero Creativity**: Given the exact same prompt, the model will output the exact same tokens in the exact same order every single time.
2. **Repetition Trap**: Because the model always picks the single most probable path, it often gets trapped in infinite sentence loops (e.g., _"and then he went to the market and then he went to the market..."_).

To fix this, we need a mechanism to sample tokens probabilistically rather than always choosing rank #1.

---

# Step 2 — Internal Mechanics

### 1. Raw Logits to Normalized Probabilities

Logits ($z_i$) are unnormalized scores—they can be negative, zero, or large positive numbers. To convert them into probabilities ($P_i$) that sum to $1.0$ (or $100\%$), PyTorch applies the **Softmax** function:

$$P_i = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$$

After Softmax:

- Every token gets a probability value between $0.0$ and $1.0$.
- The sum of all 151,646 probabilities equals exactly $1.0$.

---

### 2. Argmax (`do_sample=False`) vs. Multinomial Sampling (`do_sample=True`)

Now that we have a probability distribution, the model must pick a winning token ID:

```text
Logits Output ──► Softmax ──► Probability Distribution
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
    Greedy Decoding                                    Stochastic Sampling
  (do_sample = False)                                   (do_sample = True)
            │                                                     │
            ▼                                                     ▼
 Always pick Rank #1                                Treat probabilities as
 (Argmax operation)                                 a weighted roulette wheel
            │                                                     │
            ▼                                                     ▼
  Deterministic & Rigid                                 Dynamic & Creative

```

- **Greedy Decoding (`do_sample=False`)**: Ignores the rest of the distribution and strictly picks `argmax(probabilities)`. Rank 1 wins 100% of the time.
- **Stochastic Sampling (`do_sample=True`)**: Treats the probabilities as a **weighted roulette wheel** (`torch.multinomial`). A token with a 70% probability gets picked ~70% of the time, but a token with a 20% probability still has a 20% chance of winning!

# Step 3 — Notebook Walkthrough (Cell-by-Cell)

Let's break down our Google Colab workspace into separate, clearly explained cells.

---

### 📦 Cell 1: Imports & Model Setup

**What this cell does:** Loads our libraries, downloads `Qwen/Qwen3-0.6B` into 16-bit precision on the GPU, and ensures the tokenizer's padding token is set up correctly.

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

MODEL_ID = "Qwen/Qwen3-0.6B"

print("Downloading and initializing Qwen3-0.6B...")

# Load Tokenizer
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)

# Fix pad_token_id if unassigned
if tokenizer.pad_token_id is None:
    tokenizer.pad_token_id = tokenizer.eos_token_id

# Load Model into Colab GPU VRAM
model = AutoModelForCausalLM.from_pretrained(
    MODEL_ID,
    torch_dtype=torch.float16,
    device_map="auto"
)

print(f"Model successfully loaded on device: {model.device}")

```

---

### 💬 Cell 2: Prompt Preparation

**What this cell does:** Creates a ChatML structured prompt designed to encourage a creative, multi-sentence response from Sahur, then converts it into GPU tensors.

```python
# Create ChatML message payload
messages = [
    {
        "role": "system",
        "content": "You are Sahur, a hyper-responsive Gen Z AI assistant."
    },
    {
        "role": "user",
        "content": "Give me a creative 2-sentence hot take on why sleeping early is a life cheat code."
    }
]

# Apply ChatML formatting string
formatted_prompt = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True
)

# Convert formatted string into PyTorch Tensors on GPU
inputs = tokenizer(formatted_prompt, return_tensors="pt").to("cuda")
prompt_len = inputs.input_ids.shape[1]

print(f"Prompt formatted and moved to GPU ({prompt_len} tokens).")

```

---

### 🤖 Cell 3: Deterministic Baseline (`do_sample=False`)

**What this cell does:** Runs inference using **Greedy Decoding**. It always picks the highest-scoring token at every step.

```python
print("Generating response with Greedy Decoding (do_sample=False)...")

with torch.no_grad():
    greedy_output = model.generate(
        input_ids=inputs.input_ids,
        attention_mask=inputs.attention_mask,
        max_new_tokens=64,
        pad_token_id=tokenizer.pad_token_id,
        eos_token_id=tokenizer.eos_token_id,
        do_sample=False  # Deterministic (Argmax)
    )

# Slice tensor to extract newly generated tokens
greedy_tokens = greedy_output[0][prompt_len:]
greedy_text = tokenizer.decode(greedy_tokens, skip_special_tokens=True)

print("\n--- 🤖 GREEDY OUTPUT ---")
print(greedy_text)

```

---

### 🔥 Cell 4: Stochastic Sampling (`do_sample=True`)

**What this cell does:** Toggles `do_sample=True` to activate weighted probabilistic sampling.

```python
print("Generating response with Stochastic Sampling (do_sample=True)...")

with torch.no_grad():
    sampled_output = model.generate(
        input_ids=inputs.input_ids,
        attention_mask=inputs.attention_mask,
        max_new_tokens=64,
        pad_token_id=tokenizer.pad_token_id,
        eos_token_id=tokenizer.eos_token_id,
        do_sample=True  # Unlocks probabilistic sampling
    )

# Slice tensor to extract newly generated tokens
sampled_tokens = sampled_output[0][prompt_len:]
sampled_text = tokenizer.decode(sampled_tokens, skip_special_tokens=True)

print("\n--- 🔥 SAMPLED OUTPUT ---")
print(sampled_text)

```

---

# Step 4 — Experiment: Proving Non-Determinism

To prove that `do_sample=True` introduces true statistical variance, let's run a loop executing the **exact same prompt 3 times in a row** under both modes.

### 🧪 Cell 5: The Multi-Run Variance Experiment

```python
print("=== EXPERIMENT: RUNNING 3 GENERATION PASSES ===\n")

print("1️⃣ Testing Greedy Decoding (do_sample=False):")
for i in range(3):
    with torch.no_grad():
        out = model.generate(
            **inputs,
            max_new_tokens=30,
            do_sample=False,
            pad_token_id=tokenizer.pad_token_id
        )
    text = tokenizer.decode(out[0][prompt_len:], skip_special_tokens=True).strip()
    print(f"   Pass {i+1}: {repr(text)}")

print("\n2️⃣ Testing Stochastic Sampling (do_sample=True):")
for i in range(3):
    with torch.no_grad():
        out = model.generate(
            **inputs,
            max_new_tokens=30,
            do_sample=True,
            pad_token_id=tokenizer.pad_token_id
        )
    text = tokenizer.decode(out[0][prompt_len:], skip_special_tokens=True).strip()
    print(f"   Pass {i+1}: {repr(text)}")

```

**Expected Outcome:**

- **Greedy Decoding**: Passes 1, 2, and 3 will be **100% identical character-for-character**.
- **Stochastic Sampling**: Passes 1, 2, and 3 will feature **different phrasing, word choices, and sentence structures**.

# 🛠 Mini Lab: Manual Softmax & Sampling in PyTorch

Let's strip away Hugging Face abstraction and execute Softmax + Sampling manually using raw PyTorch tensors!

Run this cell in Google Colab:

```python
import torch

# 1. Simulate raw logits output for 5 imaginary tokens
# Token 0: "No", Token 1: "Cap", Token 2: "Fr", Token 3: "Bet", Token 4: "Bruh"
simulated_logits = torch.tensor([2.0, 5.0, 1.0, 4.0, 0.5])

# 2. Convert raw logits to probabilities via Softmax
probabilities = torch.softmax(simulated_logits, dim=-1)

print("--- RAW SIMULATED LOGITS ---")
print(simulated_logits.tolist())

print("\n--- SOFTMAX PROBABILITIES ---")
for idx, prob in enumerate(probabilities):
    print(f"Token ID {idx}: {prob.item()*100:.2f}%")

print(f"Sum of probabilities: {probabilities.sum().item():.1f}")

# 3. Simulate Greedy Selection (Argmax)
greedy_choice = torch.argmax(probabilities).item()
print(f"\nGreedy Choice (Argmax) -> Token ID {greedy_choice}")

# 4. Simulate Stochastic Sampling (torch.multinomial)
samples = [torch.multinomial(probabilities, num_samples=1).item() for _ in range(10)]
print(f"10 Random Stochastic Samples -> {samples}")

```

**Observation:**
Notice how `torch.argmax()` strictly picks Token ID 1 every single time, whereas `torch.multinomial()` samples across Token IDs 1, 3, and 0 proportional to their Softmax percentages!
