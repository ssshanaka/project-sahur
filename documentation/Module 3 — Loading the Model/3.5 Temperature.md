## Lesson 3.5 — Temperature Scaling

In **Lesson 3.4**, we unlocked stochastic sampling (`do_sample=True`) and saw how it transforms a Transformer from a rigid, deterministic calculator into a probabilistic generator.

However, enabling `do_sample=True` brings a new problem: **How do we control the degree of randomness?**

How do we tell Sahur to be strict and factual when answering a math problem, but witty, expressive, and creative when giving a Gen Z hot take?

The answer is **Temperature ($T$)**—a single scalar hyperparameter that directly scales the model's output confidence before probabilities are calculated.

# Step 1 — Why does this even exist?

When Qwen3 processes a prompt, its final layer outputs raw unnormalized numerical scores called **Logits** ($z_i$) for every token in its 151,646 vocabulary.

Some tokens get high scores (e.g., $z_1 = 10.0$), while others get low scores (e.g., $z_2 = 2.0$).

If we pass raw logits directly into Softmax without modification, the probabilities represent the model's standard pretrained confidence. But what if we want to change the model's confidence without retraining its weights?

That is what Temperature does. It acts as an **entropy amplifier or suppressor** for the probability distribution.

---

# Step 2 — Internal Mechanics

### The Mathematics of Temperature

Before Softmax is calculated, PyTorch divides every raw logit score ($z_i$) by the scalar Temperature parameter ($T$):

$$P_i = \frac{e^{\frac{z_i}{T}}}{\sum_{j} e^{\frac{z_j}{T}}}$$

Where:

- $z_i$ = Raw logit output for token $i$.
- $T$ = Temperature scalar ($T > 0$).
- $P_i$ = Final Softmax probability for token $i$.

---

### Deep Dive: The 3 Temperature Regimes

Let's trace what happens mathematically using two imaginary token logits:

$\text{Token A } (z_A = 10.0)$ vs. $\text{Token B } (z_B = 2.0)$.

#### 1. Standard Baseline ($T = 1.0$)

- Logits are divided by $1.0$ (unmodified).
- $\text{Token A}$ maintains a dominant lead over $\text{Token B}$.

#### 2. Low Temperature ($T < 1.0$, e.g., $T = 0.2$)

- We divide logits by $0.2$:
  $$\frac{z_A}{0.2} = \frac{10.0}{0.2} = 50.0$$

$$\frac{z_B}{0.2} = \frac{2.0}{0.2} = 10.0$$

- The gap between scores explodes from a difference of **8.0** to **40.0**!
- When exponential $e^x$ is applied in Softmax, $e^{50}$ completely overwhelms $e^{10}$. Token A's probability jumps to $99.99\%$, while Token B drops to near zero.
- **Result**: Low temperature **sharpens** the distribution into steep peaks. As $T \to 0$, stochastic sampling collapses into Greedy Decoding.

#### 3. High Temperature ($T > 1.0$, e.g., $T = 2.0$)

- We divide logits by $2.0$:
  $$\frac{z_A}{2.0} = \frac{10.0}{2.0} = 5.0$$

$$\frac{z_B}{2.0} = \frac{2.0}{2.0} = 1.0$$

- The gap between scores shrinks from **8.0** down to **4.0**!
- Softmax flattens out. Token B gets a significantly higher probability slice than it had before.
- **Result**: High temperature **flattens** the distribution toward uniform randomness. Rare, improbable tokens suddenly get a real chance of being sampled.

# Step 3 — Notebook Walkthrough (Cell-by-Cell)

Let's execute this in your Google Colab workspace.

---

### 📦 Cell 1: Environment & Model Initialization

**What this cell does:** Imports PyTorch and Hugging Face, then loads `Qwen/Qwen3-0.6B` onto the T4 GPU.

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

MODEL_ID = "Qwen/Qwen3-0.6B"

print("Loading tokenizer and model...")
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)

if tokenizer.pad_token_id is None:
    tokenizer.pad_token_id = tokenizer.eos_token_id

model = AutoModelForCausalLM.from_pretrained(
    MODEL_ID,
    torch_dtype=torch.float16,
    device_map="auto"
)

print(f"Model successfully mounted on GPU: {model.device}")

```

---

### 💬 Cell 2: Creating a Test Prompt

**What this cell does:** Constructs a ChatML conversation prompt requiring creative output.

```python
messages = [
    {
        "role": "system",
        "content": "You are Sahur, a hyper-responsive Gen Z AI assistant."
    },
    {
        "role": "user",
        "content": "Why is coffee the ultimate survival tool for students?"
    }
]

formatted_prompt = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True
)

inputs = tokenizer(formatted_prompt, return_tensors="pt").to("cuda")
prompt_len = inputs.input_ids.shape[1]

print(f"Prompt encoded into {prompt_len} input tokens.")

```

---

### 🧊 Cell 3: Low Temperature Generation ($T = 0.2$)

**What this cell does:** Generates text with $T = 0.2$. The output will be focused, conservative, and safe.

```python
print("Generating with Low Temperature (T = 0.2)...")

with torch.no_grad():
    low_temp_out = model.generate(
        input_ids=inputs.input_ids,
        attention_mask=inputs.attention_mask,
        max_new_tokens=50,
        pad_token_id=tokenizer.pad_token_id,
        eos_token_id=tokenizer.eos_token_id,
        do_sample=True,
        temperature=0.2
    )

text_low = tokenizer.decode(low_temp_out[0][prompt_len:], skip_special_tokens=True)

print("\n--- 🧊 LOW TEMP (T = 0.2) OUTPUT ---")
print(text_low)

```

# Step 4 — Experiment: The Full Temperature Sweep

Let's run a single loop that steps across 5 temperature points so you can observe the exact transition from rigidity to perfection to chaos.

### 🧪 Cell 6: Temperature Sweep Experiment

```python
temperatures = [0.1, 0.5, 0.8, 1.4, 2.5]

print("=== 🧪 TEMPERATURE SWEEP EXPERIMENT ===\n")

for temp in temperatures:
    with torch.no_grad():
        out = model.generate(
            input_ids=inputs.input_ids,
            attention_mask=inputs.attention_mask,
            max_new_tokens=40,
            pad_token_id=tokenizer.pad_token_id,
            eos_token_id=tokenizer.eos_token_id,
            do_sample=True,
            temperature=temp
        )

    decoded = tokenizer.decode(out[0][prompt_len:], skip_special_tokens=True).strip()
    print(f"T = {temp:<3} | {repr(decoded)}")
    print("-" * 60)

```

**Observation:**

- At **$T = 0.1$**, the text uses standard, predictable dictionary choices.
- At **$T = 0.8$**, the text flows naturally with varied vocabulary.
- At **$T = 2.5$**, grammar completely breaks down because low-ranked noise tokens are chosen almost as often as high-ranked tokens!

# 🧠 Mental Model

Think of Temperature like the flame on a kitchen stove:

- **$T \to 0$ (Frozen Ice)**: Zero heat. The model freezes onto the single tallest peak. Safe, but completely cold and lifeless.
- **$T = 0.7 - 0.8$ (Perfect Simmer)**: The ideal cooking temperature. Everything mixes smoothly, allowing creative flavor while keeping the dish structured.
- **$T \ge 2.0$ (Kitchen Fire)**: Excessive heat. Everything burns to ash. The Transformer's internal attention logic melts into unconstrained statistical noise.

# 🛠 Mini Lab: PyTorch Math Verification

Let's prove the temperature scaling math using raw PyTorch tensors without Hugging Face wrappers!

Run this cell in Google Colab:

```python
import torch

# 1. Define 3 raw logits
# Token 0 ("Yes"), Token 1 ("Maybe"), Token 2 ("Banana")
logits = torch.tensor([8.0, 4.0, 1.0])

# 2. Compute Softmax at T = 0.2, T = 1.0, and T = 2.0
prob_cold = torch.softmax(logits / 0.2, dim=-1)
prob_norm = torch.softmax(logits / 1.0, dim=-1)
prob_hot  = torch.softmax(logits / 2.0, dim=-1)

print("--- RAW LOGITS: [8.0, 4.0, 1.0] ---")
print(f"Token 0 ('Yes')   | Token 1 ('Maybe') | Token 2 ('Banana')")
print("-" * 55)

print("T = 0.2 (Cold) :", [f"{p*100:.2f}%" for p in prob_cold.tolist()])
print("T = 1.0 (Normal):", [f"{p*100:.2f}%" for p in prob_norm.tolist()])
print("T = 2.0 (Hot)  :", [f"{p*100:.2f}%" for p in prob_hot.tolist()])

```

**Observation:**
Notice how at $T = 0.2$, Token 0 commands **99.97%** of the probability. At $T = 2.0$, Token 2 ("Banana") jumps from $0.09\%$ up to **3.01%**!
