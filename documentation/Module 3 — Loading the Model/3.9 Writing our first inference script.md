# Step 1 — Why does this even exist?

Up until now, whenever we ran `model.generate()`, your notebook cell locked up for 2 to 5 seconds, and then the entire paragraph appeared all at once.

Why? Because standard `model.generate()` is a **blocking function**. It runs the full $\mathcal{O}(N)$ KV Cache loop, accumulates the token IDs in a massive 2D tensor, and only returns control to Python once the `<|im_end|>` token is hit or `max_new_tokens` is reached.

For a production assistant, a 5-second blank delay is unacceptable UX (User Experience). We need the user to see the first word within 200 milliseconds. We need a pipeline that "catches" each token the exact millisecond it emerges from the Softmax layer and prints it to the screen.

Furthermore, we need an architecture that initializes the heavy 1.2 GB model exactly **once**, and then keeps it warm in VRAM for continuous queries, rather than re-downloading or re-mounting the model for every single message.

# Step 2 — Internal Mechanics

### 1. The Streaming Pipeline (`TextStreamer`)

Hugging Face provides a beautiful utility class called `TextStreamer`. Instead of waiting for `model.generate()` to finish, `TextStreamer` acts as an asynchronous hook.

Here is the exact lifecycle of a streaming forward pass:

```text
[ GPU VRAM ]                          [ CPU SYSTEM RAM ]                  [ COLAB CONSOLE ]
                                               │
1. Model predicts Token ID #1042               │
         │                                     │
         ▼                                     ▼
2. Streamer intercepts ID 1042  ──►  Tokenizer decodes to "Bro"  ──►  Prints "Bro" instantly
         │                                     │
3. Loop continues...                           │
         │                                     │
         ▼                                     ▼
4. Model predicts Token ID #891                │
         │                                     │
         ▼                                     ▼
5. Streamer intercepts ID 891   ──►  Tokenizer decodes to " what" ──►  Prints " what" instantly

```

### 2. Skipping the Prompt (`skip_prompt=True`)

There is a catch. When `model.generate()` runs, the tensor it works with contains **both** your input prompt and the newly generated tokens. If you attach a streamer without constraints, the streamer will immediately print your entire ChatML system prompt back to your screen before printing the answer.

By passing `skip_prompt=True` into the streamer, we tell it: _"Ignore the first $N$ tokens that were passed in as context. Only decode and print the new tokens generated by the autoregressive loop."_

### 📦 Cell 1: Architecture Imports

**What this cell does:** Imports PyTorch, the core Transformers classes, and the crucially important `TextStreamer`.

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM, TextStreamer
import warnings

# Suppress minor HuggingFace warnings for a clean console output
warnings.filterwarnings("ignore")

```

---

### 🏗️ Cell 2: The Object-Oriented Inference Class

**What this cell does:** We wrap all our logic from Lessons 3.1 through 3.8 into a single, cohesive Python class. Notice how the heavy lifting (loading the model) happens in `__init__`, while the lightweight work (tokenizing text) happens in `chat()`.

```python
class SahurInferenceEngine:
    def __init__(self, model_id="Qwen/Qwen3-0.6B"):
        print(f"🔧 Initializing Project Sahur Engine...")
        print(f"📥 Loading weights for {model_id} into GPU VRAM. Please wait...")

        # 1. Load Tokenizer
        self.tokenizer = AutoTokenizer.from_pretrained(model_id)
        if self.tokenizer.pad_token_id is None:
            self.tokenizer.pad_token_id = self.tokenizer.eos_token_id

        # 2. Load Model to GPU in FP16
        self.model = AutoModelForCausalLM.from_pretrained(
            model_id,
            torch_dtype=torch.float16,
            device_map="auto"
        )

        # 3. Initialize Text Streamer (skip_prompt ensures we don't print the user's question twice)
        self.streamer = TextStreamer(self.tokenizer, skip_prompt=True, skip_special_tokens=True)

        # 4. Define our Golden Sampling Config (from Lessons 3.4 - 3.7)
        self.generation_config = {
            "max_new_tokens": 150,
            "do_sample": True,
            "temperature": 0.8,
            "top_k": 50,
            "top_p": 0.90,
            "repetition_penalty": 1.15, # Scales down logits of already-seen tokens to prevent loops
            "pad_token_id": self.tokenizer.pad_token_id,
            "eos_token_id": self.tokenizer.eos_token_id,
            "use_cache": True # Ensure KV Cache is ON (from Lesson 3.8)
        }

        print("✅ Engine online and ready.\n")

    def chat(self, user_message):
        # Format the prompt using ChatML
        messages = [
            {"role": "system", "content": "You are Sahur, a hyper-responsive Gen Z AI assistant."},
            {"role": "user", "content": user_message}
        ]

        prompt = self.tokenizer.apply_chat_template(
            messages,
            tokenize=False,
            add_generation_prompt=True
        )

        # Move inputs to CUDA
        inputs = self.tokenizer(prompt, return_tensors="pt").to(self.model.device)

        print("\n🤖 Sahur: ", end="") # Print prefix before stream starts

        # Execute the Autoregressive Loop with the Streamer attached
        with torch.no_grad():
            self.model.generate(
                **inputs,
                streamer=self.streamer,
                **self.generation_config # Dictionary unpacking injects all our sampling hyperparams!
            )
        print("\n" + "─"*50)

```

---

### 💬 Cell 3: The Interactive Loop

**What this cell does:** Initializes our engine and triggers a continuous `while` loop so you can chat back and forth inside your Colab notebook without re-running the cell.

```python
# 1. Instantiate the Engine (this mounts the model)
sahur = SahurInferenceEngine()

print("💬 Chat session started! (Type 'exit' or 'quit' to end)")
print("─"*50)

# 2. Run the continuous interactive loop
while True:
    try:
        user_input = input("🧑 You: ")

        if user_input.lower() in ['exit', 'quit']:
            print("👋 Ending session. Peace out!")
            break

        if not user_input.strip():
            continue

        # Trigger the streaming inference pass
        sahur.chat(user_input)

    except KeyboardInterrupt:
        # Graceful exit if you hit the Stop button in Colab
        print("\n👋 Session interrupted by user. Peace out!")
        break

```
