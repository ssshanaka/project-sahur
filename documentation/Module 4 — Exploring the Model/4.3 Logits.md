# What Is a Logit?

A logit is simply

> **A raw score assigned to every token in the vocabulary.**

That's it.

Not a probability.

Not a percentage.

Just a score.

# Why Every Token Gets Logits

Imagine

```text
Hello

world
```

The model doesn't only predict

after

"world."

It computes logits for every position during the forward pass.

During training,

this allows it to compare predictions at every position against the correct next token.

During generation,

we usually care only about the **last position**, because that's where the next token will be chosen.

# Inspecting the Top 5 Logits

Researchers rarely inspect

# Why Researchers Inspect Logits

Logits reveal much more than the final answer.

They let us answer questions like:

- Which token almost won?
- How confident was the model?
- Did two tokens have nearly identical scores?
- Did the model strongly prefer one answer?

This becomes especially important when debugging hallucinations or comparing different fine-tuned models.

# One Common Misconception

Many people think:

> "The highest logit is the generated token."

Not always.

If you're using **greedy decoding**, yes.

But modern LLMs often use **sampling**.

Sampling means the model may deliberately choose a lower-ranked token to produce more natural, creative, or diverse text.

We'll study this in detail when we cover decoding strategies.
