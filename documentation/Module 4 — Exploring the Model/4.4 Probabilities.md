# What Does Softmax Do?

Softmax takes

any list of numbers

and converts them into

probabilities.

Properties:

- Every probability is between **0 and 1**
- Every probability is positive
- The sum is exactly **1**

This makes them perfect for choosing the next token.

# The Magic of Exponentials

Softmax first applies

```text
eˣ
```

to every logit.

Why?

Because exponentials are **always positive**.

Examples:

```text
e² ≈ 7.39

e¹ ≈ 2.72

e⁰ = 1

e⁻¹ ≈ 0.37

e⁻⁵ ≈ 0.0067
```

Negative logits automatically become

very small positive numbers.

---

# Computing Softmax in PyTorch

Luckily,

PyTorch already provides it.

```python
import torch

probabilities = torch.softmax(
    logits,
    dim=-1
)
```

Let's understand this.

---

## `logits`

The raw scores.

---

## `dim=-1`

Apply Softmax across

the vocabulary dimension.

For Qwen3

that's

151,646 tokens.

Each generation step becomes

one probability distribution over the entire vocabulary.

---

Exactly like logits.

# What Is Entropy?

Entropy measures

how spread out

a probability distribution is.

Think of it like this:

> **Entropy answers the question: "How uncertain is the model?"**

High entropy

↓

Many possible answers.

Low entropy

↓

One obvious answer.

---


```text

```

Very confident.

Low entropy.

---

Now ask

```text

```

Suddenly

# Computing Entropy

We can compute it directly from the probabilities.

```python
entropy = -torch.sum(
    next_token_probs *
    torch.log(next_token_probs),
    dim=-1
)
```

Let's explain every piece.

---

## `torch.log()`

Computes the natural logarithm of each probability.

---

## `probabilities * log(probabilities)`

Weights each log value by its probability.

---

## `torch.sum()`

Adds everything together.

---

## Negative Sign

Without it,

entropy would be negative.

The minus sign converts it into a positive measure of uncertainty.

---

# Reading Entropy

The exact range depends on the size of the probability distribution, so it's more useful to compare entropy values than to memorize specific thresholds.

# Why Researchers Care About Entropy

Entropy is used for:

- measuring model confidence
- detecting hallucinations
- uncertainty estimation
- adaptive decoding
- active learning
- evaluating fine-tuned models
- deciding when a model should defer to another system

It's one of the simplest yet most informative signals available during generation.

---

# Softmax Isn't the End

One common misconception is:

> "The token with the highest probability is always chosen."

Not necessarily.

Generation strategies like:

- Temperature
- Top-k
- Top-p (Nucleus Sampling)

modify or sample from this probability distribution.

We'll dive into those later.
