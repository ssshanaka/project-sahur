# The Biggest Misconception About LLMs

Many people imagine an LLM generating text like this:

```text
Prompt

↓

Entire paragraph appears instantly
```

That's not what happens.

An LLM generates **one token at a time**.

Always.

---

# What Actually Happens?

Suppose our prompt is:

```text
Artificial Intelligence will
```

The model predicts one token.

Maybe:

```text
change
```

Now the prompt becomes:

```text
Artificial Intelligence will change
```

The model runs **another forward pass**.

It predicts:

```text
the
```

Now the prompt becomes:

```text
Artificial Intelligence will change the
```

Another forward pass.

Prediction:

```text
world
```

Repeat.

Every generated token causes another prediction cycle.

# Understanding the Generation Loop

Let's first understand the logic.

```text
Current Prompt

↓

Tokenize

↓

Forward Pass

↓

Extract Last Logits

↓

Softmax

↓

Top 5 Predictions

↓

Entropy

↓

Choose Token

↓

Append Token

↓

Repeat
```

Everything we've learned in Modules 4.1–4.4 happens inside this loop.

# Building the Inspector

We'll build it piece by piece.

---

# Step 1 — Load the Model

```python
from transformers import AutoTokenizer
from transformers import AutoModelForCausalLM
import torch

MODEL = "Qwen/Qwen3-0.6B"

tokenizer = AutoTokenizer.from_pretrained(MODEL)
model = AutoModelForCausalLM.from_pretrained(MODEL)

model.eval()
```

### Why `model.eval()`?

This switches the model into **evaluation mode**.

During inference, we don't want training-specific behaviors such as dropout to introduce randomness.

---

# Step 2 — Initial Prompt

```python
prompt = "Artificial Intelligence will"

inputs = tokenizer(
    prompt,
    return_tensors="pt"
)
```

Nothing new here.

We convert text into tensors.

---

# Step 3 — Generation Loop

Instead of using

```python
model.generate(...)
```

we'll manually generate one token at a time.

```python
max_new_tokens = 10

generated = inputs["input_ids"]
```

Notice something.

We're storing the growing sequence ourselves.

---

# Why `generated`?

Initially,

it contains only the prompt.

```text
Artificial Intelligence will
```

After one prediction,

it becomes

```text
Artificial Intelligence will change
```

Then

```text
Artificial Intelligence will change the
```

and so on.

---

# Step 4 — Forward Pass

Inside our loop:

```python
with torch.no_grad():
    outputs = model(input_ids=generated)
```

Notice something important.

Every iteration,

the entire sequence is fed back into the model.

Modern LLMs optimize this with **KV Cache**, which we'll study later.

For now,

understand the concept.

---

# Step 5 — Extract Last Logits

```python
next_logits = outputs.logits[:, -1, :]
```

Let's decode this.

```python
:
```

All batches.

```python
-1
```

The last token.

```python
:
```

All vocabulary items.

Result:

```text
[1,151646]
```

Exactly what we learned in Module 4.3.

---

# Step 6 — Compute Probabilities

```python
probs = torch.softmax(
    next_logits,
    dim=-1
)
```

Nothing new.

We're converting logits into probabilities.

---

# Step 7 — Top 5 Predictions

```python
values, indices = torch.topk(
    probs,
    k=5
)
```

Now decode them.

```python
for i in range(5):
    token = tokenizer.decode(indices[0][i])
    probability = values[0][i]

    print(
        token,
        probability.item()
    )
```

Now we can literally see what the model is considering.

---

# Step 8 — Compute Entropy

Exactly like last lesson.

```python
entropy = -torch.sum(
    probs *
    torch.log(probs),
    dim=-1
)
```

Now print it.

```python
print(entropy.item())
```

This tells us

how uncertain

the model currently is.

---

# Step 9 — Choose a Token

For simplicity,

we'll use greedy decoding.

```python
next_token = torch.argmax(
    probs,
    dim=-1,
    keepdim=True
)
```

Remember:

Greedy decoding simply chooses the highest-probability token.

We'll explore sampling strategies like temperature, top-k, and top-p in later modules.

---

# Step 10 — Append the Token

```python
generated = torch.cat(
    [generated, next_token],
    dim=-1
)
```

This is the magic line.

We're extending the sequence.

Before:

```text
Artificial Intelligence will
```

After:

```text
Artificial Intelligence will change
```

Now the next iteration starts with the updated sequence.

---

# Step 11 — Display the Current Text

```python
current_text = tokenizer.decode(
    generated[0],
    skip_special_tokens=True
)

print(current_text)
```

Now we can watch the sentence grow after every step.

---

# What Can We Learn?

This tool answers fascinating questions.

For example:

### Does confidence increase?

Sometimes.

As context becomes more specific,

entropy often decreases.

---

### When does confidence collapse?

Ambiguous prompts like

```text
I think
```

usually produce many competing candidates.

Entropy rises.

---

### Which words almost got selected?

Sometimes the second-ranked token is only slightly behind the first.

This reveals alternative continuations the model considered.

---

### How does fine-tuning affect confidence?

After we train Project Sahur,

we'll run this same inspector again.

We'll compare:

- Top predictions
- Probability distributions
- Entropy
- Candidate rankings

before and after fine-tuning.

It's an excellent way to evaluate whether training actually changed the model's behavior.

Token inspection is commonly used for:
