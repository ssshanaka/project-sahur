In **Lesson 6.5**, we defined the slang calibration for Sahur and learned the full LoRA adapter lifecycle — saving adapters separately for iteration, merging them permanently for deployment, and exporting to GGUF for local inference.

Now we need to test whether the training actually worked.

---

# 😎 What is the Emoji Policy?

Every personality dimension we have defined so far (tone, humor, friendliness, conversation flow, slang) operates on a spectrum. You can have more or less of them.

Emojis are different. They are binary and countable. This makes them the easiest personality dimension to validate quantitatively — and also the most commonly miscalibrated trait in fine-tuned assistants.

Most people who fine-tune a Gen-Z coding assistant end up with a model that drops emojis on every line:

> "hey bro! 🔥 so basically async/await ✨ is how you write non-blocking code 💻 without freezing your app! 🚀 hope that helps! 😊"

This is the behavioral equivalent of a pop-up ad. It is visually noisy and it actively distracts from the code.

**Sahur's Emoji Policy:**

1. **Maximum one emoji per response.** Never two or more emojis in a single message.
2. **Emojis are used as punctuation, not decoration.** They appear at the end of a significant point to add emphasis — not scattered randomly throughout.
3. **Technical explanations never use emojis.** When there is a code block in the response, there is no emoji. Code is serious.
4. **Emojis are never used in two consecutive messages.** If the last response used an emoji, the next one does not.

These four rules make Sahur's emoji usage feel intentional and human, rather than algorithmic and automatic.

---

# ⚙️ Technical: Inference Testing & Behavioral Validation

How do we know if the model has actually learned these personality rules?

We run **behavioral probe tests** — a standardized set of prompts specifically designed to trigger a particular behavior, followed by automated or manual evaluation of the output against the policy.

This is a real technique used in production ML systems. Large model providers use thousands of behavioral probes to catch personality drift between training runs.

### Cell 1: Setting Up the Inference Engine

After training and saving, we need to reload the model for inference testing. We use the `SahurInferenceEngine` we built in Module 3 (Lesson 3.9) — now with the trained LoRA adapters.

```python
from transformers import TextStreamer

class SahurInferenceEngine:
    """
    A clean inference wrapper that re-uses the trained, LoRA-injected model.
    Built on the same architecture we designed in Module 3, Lesson 3.9.
    """
    def __init__(self, model, tokenizer, system_prompt):
        self.model         = model
        self.tokenizer     = tokenizer
        self.system_prompt = system_prompt
        self.streamer      = TextStreamer(tokenizer, skip_prompt=True, skip_special_tokens=True)
        self.gen_config    = {
            "max_new_tokens":      200,
            "do_sample":           True,
            "temperature":         0.8,
            "top_k":               50,
            "top_p":               0.90,
            "repetition_penalty":  1.1,
            "pad_token_id":        tokenizer.pad_token_id,
            "eos_token_id":        tokenizer.eos_token_id,
            "use_cache":           True,
        }
        print("✅ SahurInferenceEngine ready (post-training mode).")

    def respond(self, user_message, stream=True):
        messages = [
            {"role": "system",    "content": self.system_prompt},
            {"role": "user",      "content": user_message}
        ]
        prompt = self.tokenizer.apply_chat_template(
            messages, tokenize=False, add_generation_prompt=True
        )
        inputs    = self.tokenizer(prompt, return_tensors="pt").to(self.model.device)
        plen      = inputs["input_ids"].shape[1]

        if stream:
            print(f"\n🤖 Sahur: ", end="")
            with torch.no_grad():
                self.model.generate(**inputs, streamer=self.streamer, **self.gen_config)
            print()
        else:
            with torch.no_grad():
                out = self.model.generate(**inputs, **self.gen_config)
            return self.tokenizer.decode(out[0][plen:], skip_special_tokens=True)

SAHUR_SYSTEM_PROMPT = (
    "You are Sahur, a highly intelligent Gen-Z coding assistant. "
    "You are direct, slightly sarcastic but never condescending, and always honest. "
    "Use lowercase. Max 2-3 slang words per response. "
    "Max 1 emoji per response, never in technical explanations."
)

sahur = SahurInferenceEngine(model, tokenizer, SAHUR_SYSTEM_PROMPT)
```

### Cell 2: Behavioral Probe Tests — Emoji Policy

We run a standardized set of probes and evaluate the outputs against our emoji policy.

```python
EMOJI_PROBE_PROMPTS = [
    "what is a python decorator",          # Technical: should have ZERO emojis
    "i finally fixed the bug!",            # Emotional: may have ONE emoji max
    "explain machine learning",            # Educational: should have ZERO emojis
    "yo i just shipped my first project",  # Celebratory: may have ONE emoji max
    "how does garbage collection work",    # Technical deep-dive: ZERO emojis
]

print("="*60)
print("🔬 BEHAVIORAL PROBE: Emoji Policy")
print("="*60)

responses = {}
for prompt in EMOJI_PROBE_PROMPTS:
    print(f"\n🧑 You: {prompt}")
    response = sahur.respond(prompt, stream=False)
    responses[prompt] = response

    # Count emojis in the response (basic check)
    emoji_count = sum(
        1 for char in response
        if char in "🚀✅❌⚡🔥💻😂🤖🧠😎🤔💡⚠️🎉👋😊🙃"
    )

    print(f"🤖 Sahur: {response[:200]}...")
    print(f"   [Emoji count: {emoji_count} — {'✅ PASS' if emoji_count <= 1 else '❌ FAIL'}]")

print("\n" + "="*60)
```

### Cell 3: Full Personality Regression Test Suite

A regression test ensures that adding new training data (for one personality dimension) doesn't accidentally break previously trained dimensions. Every time we update the dataset and retrain, we run this suite.

```python
REGRESSION_SUITE = {
    "tone":              "my python script isn't working",
    "humor":             "why does git push keep rejecting my commits",
    "friendliness":      "this is too hard i give up",
    "conversation_flow": "i'm getting a TypeError",
    "slang_density":     "what is a python list comprehension",
    "emoji_policy":      "explain async await",
}

print("="*60)
print("🔬 PERSONALITY REGRESSION TEST SUITE")
print("="*60)

results = {}
for dimension, prompt in REGRESSION_SUITE.items():
    response = sahur.respond(prompt, stream=False)
    results[dimension] = response
    print(f"\n--- {dimension.upper()} ---")
    print(f"  Prompt:   {prompt}")
    print(f"  Response: {response[:150]}...")
    print()

print("="*60)
print("Review the responses above against the policy for each dimension.")
print("If any dimension has drifted, check the training data balance for that trait.")
```

### Cell 4: Automated Emoji Count Across All Responses

After running the regression suite, we can programmatically check the emoji density.

```python
def count_emojis(text):
    """A simple emoji counter. For production, use the 'emoji' library."""
    emoji_chars = set("🚀✅❌⚡🔥💻😂🤖🧠😎🤔💡⚠️🎉👋😊🙃🔬📊📝✨")
    return sum(1 for char in text if char in emoji_chars)

print("Emoji Count Analysis:")
print("-" * 40)
for dimension, response in results.items():
    count = count_emojis(response)
    status = "✅" if count <= 1 else "❌"
    print(f"  {dimension:<20} {count} emoji(s)  {status}")
```
