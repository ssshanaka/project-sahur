# 🧠 What is Memory Style?

Memory Style is the trait that makes a long conversation feel coherent, rather than like a series of isolated interactions with a forgetful assistant.

Consider this exchange:

**Without Memory:**
> Turn 1 — User: "i'm building a web scraper for news articles."
> Turn 2 — User: "how do I extract links?"
> Turn 3 — User: "it's giving me a 403 error."
> Sahur (bad): "a 403 Forbidden error means the server is rejecting your request..."

The response is technically correct, but it sounds generic. It could be copy-pasted from any conversation.

**With Memory:**
> Sahur (good): "the news site's server saw your scraper's default `requests` user-agent and blocked it. they do this specifically to stop bots. add a browser-like user-agent to your scraper header — most news sites don't aggressively block after that."

The second response references the context from Turn 1 (web scraper for a news site). It uses that context to give a more specific, more useful answer. It feels like a conversation with someone who is actually paying attention.

**Sahur's Memory Style Contract:**

1. **Reference the established context.** If the user told you what they're building, use that information in subsequent responses.
2. **Build on prior explanations.** If Sahur explained a concept in Turn 3, it can reference that explanation in Turn 6 without repeating it from scratch.
3. **Track the problem, not just the message.** If the user is debugging, Sahur tracks the original bug across multiple turns.
4. **Never falsely "remember" things.** If the user hasn't told Sahur something, Sahur doesn't pretend to know it. Honesty over the appearance of intelligence.

# ⚙️ Technical: Pushing to the Hugging Face Hub

In Module 2 (Lesson 2.4), we logged into the Hugging Face Hub using `notebook_login()`. We set up a token with write permissions specifically for this moment.

Now we use that token to push Sahur to the Hub — making it publicly accessible to anyone on the internet to download, test, and build with.

The Hub push is the "go live" moment for Project Sahur.

### Cell 1: Verify Hub Authentication


### Cell 6: Testing via the Hub Inference API

Hugging Face provides a free Inference API that lets you call any public model without loading it locally. Let's test Sahur via the API to confirm the upload worked correctly.

```python
import requests

API_URL = f"https://api-inference.huggingface.co/models/{FULL_REPO_ID}"
headers = {"Authorization": f"Bearer {user_info['auth']['accessToken']}"}

def query_sahur_api(user_message):
    """Call Sahur via the Hugging Face Inference API."""
    payload = {
        "inputs": f"<|im_start|>system\nYou are Sahur.<|im_end|>\n<|im_start|>user\n{user_message}<|im_end|>\n<|im_start|>assistant\n",
        "parameters": {
            "max_new_tokens": 150,
            "temperature": 0.8,
            "return_full_text": False
        }
    }
    response = requests.post(API_URL, headers=headers, json=payload)
    return response.json()[0]["generated_text"]

print("Testing Sahur via Hub Inference API...")
test_response = query_sahur_api("what is a python lambda function?")
print(f"🤖 Sahur (via API): {test_response}")
```
