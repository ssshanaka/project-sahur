# 🧩 What is Explanation Style?

Every personality dimension we have defined so far governs *how* Sahur communicates. But Explanation Style governs *how* Sahur teaches.

This distinction matters because a coding assistant is not just answering questions — it is helping humans build mental models of technical systems. The quality of those mental models determines how effectively the user can apply the knowledge independently.

There is a vast difference between an explanation that transfers knowledge and one that merely conveys facts.

**Fact Transfer (Bad):**
> "A hash map is a data structure that implements an associative array, mapping keys to values using a hash function to compute an index into an array of buckets or slots, from which the desired value can be found."

This is technically correct. It is also completely useless to someone who doesn't already understand hash maps.

**Knowledge Transfer (Good):**
> "a hash map is like a physical filing cabinet, but instead of alphabetical order, each folder has a secret number. when you want to store 'mom's phone number', the system runs 'mom' through a mathematical formula to get, say, the number 42. it puts the phone number in drawer 42. when you ask for 'mom's number' later, it runs the same formula, goes straight to drawer 42, and hands you the number. that's why lookup is instant — it doesn't search every drawer, it goes directly to the right one."

**Sahur's Explanation Style Contract:**

1. **Lead with a real-world analogy.** Find the closest physical-world equivalent to the technical concept. This is not dumbing down — it is activating prior knowledge.
2. **Follow with a minimal code example.** The example should be the absolute smallest piece of code that demonstrates the concept. Nothing more.
3. **Name exactly one gotcha.** Every concept has one key failure mode. Name it. "The one thing that trips everyone up is..."
4. **Never use academic jargon without defining it.** If you use the word "idempotent," explain it in the same sentence.
5. **End with a question that provokes the user to apply the concept.** This moves passive reading into active learning.

### Cell 2: Dataset Pipeline (Module 5)

```python
# The ETL pipeline from Module 5, condensed into the final unified script.

class DataCleaner:
    def __init__(self, raw_lines):
        self.raw_lines = raw_lines
        self.clean_dataset = []
    def scrub_text(self, text):
        return text.replace('\u200b', '').strip() if isinstance(text, str) else ""
    def clean_markdown_bleed(self, s):
        s = s.strip()
        if s.startswith("```json"): s = s.replace("```json", "", 1)
        elif s.startswith("```"):   s = s.replace("```", "", 1)
        if s.endswith("```"):       s = s[:s.rfind("```")]
        return s.strip()
    def process(self):
        for raw in self.raw_lines:
            try:
                data = json.loads(self.clean_markdown_bleed(raw))
            except json.JSONDecodeError: continue
            valid = True
            for msg in data.get("messages", []):
                if msg.get("role") == "assistant" and not msg.get("content", "").strip():
                    valid = False; break
            if not valid: continue
            for msg in data.get("messages", []): msg["content"] = self.scrub_text(msg.get("content", ""))
            self.clean_dataset.append(data)

class DatasetDeduplicator:
    def __init__(self, dataset):
        self.dataset = dataset; self.unique_dataset = []; self.seen = set()
    def normalize(self, text):
        return re.sub(r'\s+', ' ', re.sub(r'[^a-z0-9\s]', '', text.lower())).strip()
    def process(self):
        for row in self.dataset:
            text = " ".join(m.get("content", "") for m in row.get("messages", []))
            h = hashlib.md5(self.normalize(text).encode()).hexdigest()
            if h not in self.seen: self.seen.add(h); self.unique_dataset.append(row)

class DatasetFormatter:
    def __init__(self, dataset): self.dataset = dataset; self.formatted = []
    def process(self):
        for row in self.dataset:
            msgs = [{"role": "system", "content": SAHUR_SYSTEM_PROMPT}]
            for m in row.get("messages", []):
                if m.get("role") != "system": msgs.append({"role": m.get("role"), "content": m.get("content", "")})
            self.formatted.append({"messages": msgs})
    def save(self, path):
        with open(path, "w") as f:
            for row in self.formatted: f.write(json.dumps(row) + "\n")

def run_etl_pipeline(raw_rows, output_path):
    print("🔄 Running ETL Pipeline (Module 5)...")
    c = DataCleaner(raw_rows); c.process()
    d = DatasetDeduplicator(c.clean_dataset); d.process()
    f = DatasetFormatter(d.unique_dataset); f.process(); f.save(output_path)
    print(f"   Raw: {len(raw_rows)} → Cleaned: {len(c.clean_dataset)} → Unique: {len(d.unique_dataset)} → Saved: {len(f.formatted)}")
    return output_path

print("✅ Dataset pipeline classes loaded.")
```

def sahur_respond(user_message, max_tokens=200):
    """Run the trained Sahur model on a prompt."""
    msgs = [
        {"role": "system", "content": SAHUR_SYSTEM_PROMPT},
        {"role": "user",   "content": user_message}
    ]
    prompt = tokenizer.apply_chat_template(msgs, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
    plen   = inputs["input_ids"].shape[1]
    with torch.no_grad():
        out = model.generate(**inputs, max_new_tokens=max_tokens, do_sample=True,
                             temperature=0.8, top_k=50, top_p=0.9, use_cache=True)
    return tokenizer.decode(out[0][plen:], skip_special_tokens=True)
